CSV: ¿qué es?

  • Un archivo de texto plano: puedes abrirlo con el Bloc de notas.
  • Cada línea es una fila; los valores se separan con una coma.
  • La primera línea son los nombres de las columnas.
  • Es el formato más común: casi todo sistema sabe exportarlo.
Así se ve por dentro
order_id,payment_type,payment_value
b81ef2...,credit_card,99.33
a9810d...,credit_card,24.39
25e8ea...,boleto,65.71

Excel: una planilla con varias hojas

  • Los reportes de gerencia llegan en Excel, casi siempre con varias hojas: una por mes, una por sucursal...
  • Antes de leer, hay que saber qué hojas hay.
  • Después se lee una hoja a la vez, por su nombre.
  • pandas usa openpyxl por detrás (ya está instalado).
Nuestro ejemplo
archivo: reporte_demo.xlsx
  hoja "Ventas"    → region, ventas
  hoja "Clientes"  → region, clientes

# 1) Creamos un Excel de ejemplo (simula un reporte que te mandan)
ventas = pd.DataFrame({
    "region": ["RM", "Biobío", "Valparaíso"],
    "ventas": [1200, 800, 950],
})
clientes = pd.DataFrame({
    "region": ["RM", "Biobío", "Valparaíso"],
    "clientes": [45, 30, 38],
})

with pd.ExcelWriter("data/reporte_demo.xlsx") as escritor:
    ventas.to_excel(escritor, sheet_name="Ventas", index=False)
    clientes.to_excel(escritor, sheet_name="Clientes", index=False)
print("Excel creado: data/reporte_demo.xlsx")
Qué significa

with pd.ExcelWriter(...) abre un Excel para escribir; al terminar el bloque, lo cierra solo.
as escritor le damos un nombre al archivo abierto.
sheet_name="Ventas" el nombre de la hoja.
index=False no guardes la columna de números 0, 1, 2 que pandas agrega.

JSON: diccionarios y listas, uno dentro de otro

  • Es el formato en que responden las APIs y los sistemas web.
  • Es lo que ya conoces: diccionarios { } y listas [ ], anidados.
  • Para llegar a un dato hay que entrar de a un nivel.
  • Al final, lo aplanamos en una tabla.
Un JSON de ejemplo
{ "marketplace": "Olist",
  "vendedores": [
     {"vendedor": "Tienda A", ...},
     {"vendedor": "Tienda B", ...}
  ] }

03_json.py · Leamos línea por línea (1/2)

# Así llega un JSON desde una API: un diccionario con una lista adentro
respuesta = {
    "marketplace": "Olist",
    "vendedores": [
        {"vendedor": "Tienda A", "estado": "SP", "ventas": 50000},
        {"vendedor": "Tienda B", "estado": "RJ", "ventas": 32000},
    ],
}

print("Marketplace:", respuesta["marketplace"])
print("Lista de vendedores:", respuesta["vendedores"])
print("El primero:", respuesta["vendedores"][0])
print("Su nombre:", respuesta["vendedores"][0]["vendedor"])
Qué significa
respuesta = { ... } un diccionario que tiene adentro una lista de diccionarios.
respuesta["marketplace"] busca por clave: devuelve "Olist".
respuesta["vendedores"] busca la clave "vendedores": devuelve la lista.
[0] el primer elemento de la lista: un diccionario.
["vendedor"] de ese diccionario, el valor de la clave "vendedor".

Cómo se lee un acceso anidado

ExpresiónQué obtienes

respuesta["vendedores"][0]El primer vendedor (un diccionario)
respuesta["vendedores"][0]["vendedor"]"Tienda A"
Se lee de izquierda a derecha, entrando un nivel con cada paréntesis cuadrado: clave, posición, clave.

Parquet: el formato liviano y rápido

  • Un archivo binario (no se abre con el Bloc de notas), guarda los datos por columna y los comprime.
  • Pesa menos y se lee más rápido que un CSV: por eso es el preferido en la nube.
  • Necesita la librería pyarrow (la instalamos al inicio).
  • Lo usaremos para guardar los resultados de tu proyecto.
Nuestro ejemplo (aprox.)
pagos.csv      5,8 MB
pagos.parquet  3,8 MB

04_parquet.py · Leamos línea por línea (1/2)

import os
import pandas as pd

RUTA = "data/raw/"
pagos = pd.read_csv(RUTA + "olist_order_payments_dataset.csv")

pagos.to_parquet("data/pagos.parquet", index=False)   # guarda en Parquet
leido = pd.read_parquet("data/pagos.parquet")         # lo vuelve a leer
print("Filas leídas desde Parquet:", len(leido))
Qué significa
import os trae herramientas para consultar archivos (su tamaño).
pagos = pd.read_csv(...) leemos el CSV, como ya sabemos.
pagos.to_parquet(...) guarda la tabla en formato Parquet.
index=False sin la columna de números 0, 1, 2.
pd.read_parquet(...) lo vuelve a leer: queda otra tabla igual.
len(leido) cuenta las filas: debe ser igual que en el CSV.

¿Qué es una API?

🧑‍💻
Tu script
Es el cliente: el que pide datos. Como un comensal.
🛎️
La API
Es el garzón: recibe el pedido, lo lleva y trae la respuesta.
🗄️
El servidor
Es la cocina: tiene los datos y los prepara.
Una API es una dirección web que devuelve datos (en JSON) en lugar de una página. Hoy usamos mindicador.cl: indicadores de Chile (dólar, UF, euro...).
Diplomado en Ingeniería de Datos con Python

Una API por dentro: dirección y respuesta

CódigoQué significaEn la práctica
200Todo bienLlegaron los datos
404No existe esa direcciónRevisa la URL
500Falló el servidorNo es tu culpa: reintenta más tarde
La dirección https://mindicador.cl/api tiene tres partes: el protocolo (https), el sitio (mindicador.cl) y el camino (/api). La respuesta llega como texto JSON, y Python la convierte en un diccionario.

05_api.py · Leamos línea por línea (1/3)

URL = "https://mindicador.cl/api"

try:
    respuesta = requests.get(URL, timeout=10)    # pedimos los datos
    respuesta.raise_for_status()                 # si hubo error, avisa
    print("Código de respuesta:", respuesta.status_code)
Qué significa
URL = "..." la dirección de la API, guardada en una variable.
try: "intenta hacer esto": si algo falla, salta al except.
requests.get(URL, timeout=10) "dame los datos de esta dirección"; espera máximo 10 segundos.
raise_for_status() si la API respondió con un error (404, 500...), avisa.
status_code el código de respuesta: 200 es "todo bien".
Diplomado en Ingeniería de Datos con Python

try / except: ¿y si no hay internet?

  • Internet puede fallar o ser lento: es normal.
  • try: = "intenta esto". Si todo sale bien, el except se ignora.
  • Si falla, Python salta al except y muestra un mensaje claro, sin llenar la pantalla de letras rojas.
  • timeout=10: si no responde en 10 segundos, se corta.
Qué verás
Con internet:
  Código de respuesta: 200

Sin internet:
  No pude conectar con la API.
  Revisa tu internet...
