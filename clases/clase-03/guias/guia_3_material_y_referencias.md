## Clase 3 · Las 4 estructuras de Python y tu proyecto integrador

### Python para ciencia de datos: lo básico

- **Python.org — El tutorial oficial de Python, cap. 5 «Estructuras de datos»** — [docs.python.org/es/3/tutorial/datastructures.html](https://docs.python.org/es/3/tutorial/datastructures.html) `GRATIS`
  *Está en español. Cubre listas, tuplas, sets y diccionarios, exactamente lo visto hoy. El cap. 3 (introducción) y el cap. 4 (control de flujo, donde aparece el for) lo complementan.*

- **W3Schools — Python Lists, Tuples, Sets y Dictionaries** — [Lists](https://www.w3schools.com/python/python_lists.asp) · [Tuples](https://www.w3schools.com/python/python_tuples.asp) · [Sets](https://www.w3schools.com/python/python_sets.asp) · [Dictionaries](https://www.w3schools.com/python/python_dictionaries.asp) `GRATIS`
  *Una página por estructura, en inglés, con ejemplos cortos que puedes ejecutar en el navegador. Útil para consultar sintaxis puntual.*

- **Sweigart, A. — Automate the Boring Stuff with Python (3ª ed.), cap. 6 (Lists) y cap. 7 (Dictionaries and Structuring Data)** — [automatetheboringstuff.com/3e/chapter6.html](https://automatetheboringstuff.com/3e/chapter6.html) · [cap. 7](https://automatetheboringstuff.com/3e/chapter7.html) `GRATIS · LIBRO`
  *En inglés. Está escrito para personas que parten desde cero, con ejemplos cotidianos, como los de la clase.*

- **Severance, C. — Python for Everybody** — [py4e.com](https://www.py4e.com/) · [lección de listas](https://www.py4e.com/lessons/lists) · [lección de diccionarios](https://www.py4e.com/lessons/dictions) `GRATIS · LIBRO`
  *Curso y libro gratuitos para principiantes, en inglés, con ejercicios. Las lecciones de listas y diccionarios repasan esta clase.*

### Practicar y ver qué hace tu código

- **Visual Studio Code — Getting Started with Python in VS Code** — [code.visualstudio.com/docs/python/python-tutorial](https://code.visualstudio.com/docs/python/python-tutorial) `GRATIS`

- **pandas — Tutorial introductorio sobre tablas (DataFrame y Series)** — [pandas.pydata.org/docs/getting_started/intro_tutorials/01_table_oriented.html](https://pandas.pydata.org/docs/getting_started/intro_tutorials/01_table_oriented.html) `GRATIS`

- **pandas — Cheat Sheet oficial (PDF, 1 página)** — [pandas.pydata.org/Pandas_Cheat_Sheet.pdf](https://pandas.pydata.org/Pandas_Cheat_Sheet.pdf) `GRATIS`

- **McKinney, W. — Python for Data Analysis (3ª ed.), cap. 3 y cap. 5** — [wesmckinney.com/book](https://wesmckinney.com/book/) `GRATIS · LIBRO`

### APIs y JSON: adelanto de la Clase 4

- **Python.org — Módulo json de la biblioteca estándar** — [docs.python.org/es/3/library/json.html](https://docs.python.org/es/3/library/json.html) `GRATIS`
